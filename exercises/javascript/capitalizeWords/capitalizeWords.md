# Weyney xarfaha
Waxaa lagu siiyay **function** kaas oo qaadanaya **jumlad**,
ka dhig belowga xarafkasta ee ereyada ku jira jumlada mid weyn.
## Tusaale

```javascript
weyneyXarfkaUguHoreeya("magaceygu waa maxamed") => "Magaceygu Waa Maxamaed"
```

```javascript
weyneyXarfkaUguHoreeya("waxaan ahay arday") => "Waxaan Ahay Arday"
```

```javascript
weyneyXarfkaUguHoreeya("waan jeclahay dalkeyga") => "Waan Jeclahay Dalkeyga"
```
