## Hel xarafka ugu dheer
Waxaa lagu siiyay **function** kaas oo qaadanaya **jumlad**,
waxaad ka soo saartaa xarafka ugu dheer **jumladaas**.

##Tusaale

```javascript
helEreygaUguDheer("Magaceygu waa Maxamed") => Magaceygu
```

```javascript
helEreygaUguDheer("Waxaan ku noolahay Soomaaliya") => Soomaaliya
```

```javascript
helEreygaUguDheer("Maalmuhu waa 7ba") => Maalmuhu
```
